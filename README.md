# りんごのみTV（RingonomiTV）

りんごのみTVは、自分で運用する録画・視聴サーバーに接続するApple TV向けの
オープンソースtvOSアプリです。現時点の対応バックエンドはKonomiTVです。
サーバーURLは初期状態では空で、アプリの設定画面から利用者が入力します。

本アプリは、[Komorebi](https://github.com/BeerEgg2001/Komorebi)の機能と通信仕様を
参考に、Swift／SwiftUI／tvOS向けに再実装しています。参照元Androidプロジェクトの
MIT著作権表示は、このリポジトリの[`LICENSE`](LICENSE)に保持しています。

## 現在の実装

- KonomiTVのチャンネル一覧、番組情報、録画一覧
- 録画ライブラリの検索・ページ送り・並べ替え・番組詳細
- 録画のチャンネル・ジャンル・曜日・シリーズ別分類
- 番組表の放送波・日付切り替え、日本語検索、番組詳細からの視聴
- 録画予約の一覧・追加・変更・削除、優先度・録画マージンなどの設定
- キーワード自動予約の作成・編集・削除、サーバー上の検索プレビュー
- キーワード条件の対象チャンネル、番組長、重複チェック、正規表現・あいまい検索
- キーワード条件のジャンル・中分類、曜日・時間帯、除外条件
- 録画一覧での録画中・一部録画の表示
- ライブ視聴と録画再生
- 1080p、720p、540p、360pの画質選択
- 再生中の画質変更と録画のシーク
- 再生エンジンが認識した音声トラックの選択
- 録画のARIB字幕表示・表示切り替え
- 録画実況の過去ログ表示と再生位置への同期
- ライブ実況の受信・表示、遅延調整と再接続
- 録画の再生位置保存、続きから／最初からの選択
- サーバーのCM区間情報に基づくチャプター一覧と前後移動
- 接続エラー、再生エラー、タイムアウト、再試行の表示
- tvOSリモコンによる再生・一時停止・録画シーク

番組表は、横にチャンネル、縦に時間を並べる形式を既定にしています。朝4時を一日の
境界とし、見出し・時間軸・現在時刻線を表示します。左右でチャンネル、上下で番組を
選び、決定で詳細を開きます。上端または戻る操作で見出しへ戻れます。
表示メニューからチャンネル別の一覧形式にも切り替えられます。番組詳細から録画予約を追加し、
「予約」タブから設定変更・削除ができます。「キーワード」から自動予約条件を管理し、
保存前に検索結果を確認できます。標準ジャンルの大分類全体または中分類を複数選べます。
曜日・時間帯は日本時間の番組開始日時で判定し、複数の範囲を指定できます。
各ジャンル内・日時範囲内は「いずれかに一致」、ジャンルと日時の組み合わせは
「両方に一致」で絞り込みます。指定したジャンルや日時を除外する設定も利用できます。
番組長の最短・最長は分単位です。
副チャンネルは設定画面から表示でき、既定では主チャンネルを並べます。

録画の再生位置はApple TVごとに保存します。前回の位置がある録画は、続きから再生するか
最初から再生するかを選べます。再生終了に近い完了済みの録画は、次回は最初から開きます。
再生画面の「チャプター」から本編・CMの開始位置へ移動できます。サーバーにCM区間情報が
ない録画では、1分戻る・3分進むの操作を利用できます。

複数の音声を認識した配信では、再生画面の「音声」から切り替えられます。
画質変更後も同じ音声を一意に識別できれば、選択を引き継ぎます。
録画の別音声を選ぶには、サーバー側の配信に音声の選択情報が含まれている必要があります。

録画再生の「実況」から、過去ログの表示・非表示を切り替えられます。右から流れる
コメントと上下の固定コメントを、色・文字サイズを反映して表示します。一時停止中は
コメントも止まり、シークや画質変更後は映像の再生位置に合わせます。重なるコメントは
間引きます。取得に失敗しても映像は再生を続け、実況メニューから再取得できます。
過去ログの提供状況は接続先サーバーと番組に依存します。

ライブ再生の「実況」から表示を切り替えられます。対応チャンネルではNX-Jikkyoから
コメントを受信し、右から流れる表示・上下固定・文字サイズ・色を反映します。
「表示の遅延」で受信後の待ち時間を0〜10秒に調整できます。映像の配信遅延は環境で
異なるため、放送時刻との厳密な同期ではなく、映像に合わせて遅延を調整してください。
一時停止・読み込み中は実況の時計を止め、再開時は滞留したコメントを流しません。
接続が途切れた場合は待ち時間を延ばしながら再接続し、実況が利用できなくても映像は
再生を続けます。「実況に再接続」で手動の再試行もできます。

録画のARIB字幕は、配信に含まれる字幕データをlibaribcaptionで解析・描画します。
再生画面の「字幕」から表示・非表示を切り替えられます。放送で指定された文字色・背景・
表示位置を映像の範囲内に反映します。字幕データがない区間では表示しません。
シークや続き再生の直後は、次の字幕データを受信するまで表示されない場合があります。
字幕の対応範囲は録画のHLS配信です。ライブ字幕と複数の字幕言語の選択は未実装です。

再生画面の操作は2段に分けています。録画の操作ボタンは、映像の下側に出る字幕と
重なりにくい上側へ配置しています。戻るボタンで再生画面を閉じます。

録画ライブラリは30件ずつ表示し、前後のページへ移動できます。番組名・シリーズ名・
サブタイトルの部分一致でサーバー上の録画を検索し、新しい順／古い順に並べ替えます。
番組を選ぶと再生し、隣の「詳細」から放送日時・チャンネル・ジャンル・番組説明を確認できます。

表示メニューからチャンネル別・ジャンル別・曜日別・シリーズ別に切り替えられます。
分類時は、検索結果の全ページを取得してから件数と一覧を表示します。曜日は日本時間の
放送開始日時を使います。シリーズ情報がない番組は、話数表記を除いた番組名が複数件で
一致する場合にまとめ、それ以外は「単発・その他」に表示します。
分類対象は最大20,000件です。上限を超える場合は検索語で絞り込んでください。
全件表示では、従来どおりサーバーのページを順に閲覧できます。

予約の変更時は最新の設定を取得し、編集した項目だけを反映します。保存先などの未編集項目は
保持し、同じ項目が別の画面で変更された場合は競合を表示します。通信が途切れて操作結果が
不明な場合、追加操作を自動再送せず、一覧から結果を確認します。録画中の予約を削除すると
録画が中止されるため、画面で明示確認します。保存先や録画後処理の編集UIは未実装です。

再生開始時に音声だけ先行して黒画面が見える状態を避けるため、ライブと録画で
別の準備処理を使います。

- **ライブ再生**はTVVLCKitを使用します。映像フレームが進み、音声も利用可能な状態が
  1秒間継続するまで画面を黒いロード表示で覆い、音声をミュートします。途中で停止した
  場合は準備状態をリセットして再開します。
- **録画再生**はAVPlayerの`seek`と`preroll`を使用します。
  先読みが完了した後、ミュートで最初の映像を準備します。映像レイヤーが表示可能になってから
  ロード表示を解除して音声を戻します。画質変更や再バッファリングでも同じ準備経路を通ります。

## 準備

Xcode 16.4以降、tvOS 17以降のSDK、Swift 6、macOSを使用します。XcodeGen、
TVVLCKit、libaribcaptionはGitにバイナリを含めていません。大きな依存ファイルを
別ボリュームに置く場合は、準備先を環境変数で指定できます。

```sh
RINGONOMITV_DEPENDENCY_ROOT="$PWD/.cache/dependencies" ./bootstrap.sh
```

`bootstrap.sh`は次の一次配布元から取得し、SHA-256を検証します。

| 依存物 | 取得元 | SHA-256 |
| --- | --- | --- |
| XcodeGen 2.46.0 | [公式リリース](https://github.com/yonaskolb/XcodeGen/releases/tag/2.46.0) / [xcodegen.zip](https://github.com/yonaskolb/XcodeGen/releases/download/2.46.0/xcodegen.zip) | `4d9e34b62172d645eed6457cac13fc222569974098ef4ee9c3368bedf0196806` |
| TVVLCKit 3.7.0 | [VideoLAN公式アーカイブ一覧](https://downloads.videolan.org/cocoapods/prod/) / [TVVLCKit-3.7.0 archive](https://downloads.videolan.org/cocoapods/prod/TVVLCKit-3.7.0-591b8996-f9020c4d.tar.xz) | `de9afabd53b914e234adf39f1f9b7f71d6f8c19bbfc009c8388a2eb0657a16e3` |
| libaribcaption 1.1.2 | [固定コミット](https://github.com/xqq/libaribcaption/tree/37dde0f32652c32aa98bf92278944d1cfb2e7354) / [公式アーカイブ](https://codeload.github.com/xqq/libaribcaption/tar.gz/37dde0f32652c32aa98bf92278944d1cfb2e7354) | `ace54ae69e1b38481917d36161a8960ed93f51f7fd343575fab36dfe3ea072f6` |

TVVLCKitの公式URLが利用できない場合、スクリプトはXcodeGenの準備までを行い、
TVVLCKitは手動配置するよう案内して終了します。推測したミラーや別のURLからは
取得しません。手動配置先は`Vendor/TVVLCKit-binary/TVVLCKit.xcframework`です。
TVVLCKitのソースとライセンスは[VideoLAN VLCKit](https://code.videolan.org/videolan/VLCKit/)
を参照してください。

字幕の描画にはlibaribcaption 1.1.2を固定コミットで使用します。`bootstrap.sh`の最後に
`prepare-captions.sh`が呼ばれ、CMake 3.28以降とXcodeのtvOS SDKで、CoreTextを有効にした
C++17の静的ライブラリをtvOS device arm64、Simulator arm64／x86_64向けに生成します。
FreeTypeとFontconfigは使用しません。2つのSimulatorアーキテクチャを`lipo`でまとめ、
`xcodebuild -create-xcframework`で`Vendor/ARIBCaption/libaribcaption.xcframework`を
作成します。生成物、ソース、アーカイブは`RINGONOMITV_DEPENDENCY_ROOT`（既定は
`.cache/dependencies`）とGit管理外の`Vendor`に置かれます。固定コミットと構成は
`Vendor/ARIBCaption/libaribcaption.version`で確認できます。

libaribcaptionの著作権表示とMITライセンスは
[`App/Licenses/libaribcaption-MIT.txt`](App/Licenses/libaribcaption-MIT.txt)に、内蔵MD5
実装の通知は[`App/Licenses/libaribcaption-MD5-notice.txt`](App/Licenses/libaribcaption-MD5-notice.txt)
に同梱しています。

準備後のSwiftパッケージテストとtvOSビルドは次のとおりです。

```sh
./test.sh
CODE_SIGNING_ALLOWED=NO ./build.sh
```

`build.sh`は`xcode-select`で選択されたXcodeを使います。別のXcodeを使う場合は
`DEVELOPER_DIR`を指定できます。生成される`RingonomiTV.xcodeproj`、TVVLCKit、
ビルド成果物、ログ、キャッシュはGit管理外です。
ソースの追加・更新もXcodeGenのキャッシュで確認し、必要なときにプロジェクトを再生成します。

## Apple TVへの配置

`deploy.sh`の最初の引数はXcodeで確認したApple TVのデバイス識別子です。2番目以降の
引数はそのまま`xcodebuild`へ渡されるため、署名Teamなどのローカル設定をコマンドライン
で指定できます。

```sh
./deploy.sh DEVICE_IDENTIFIER DEVELOPMENT_TEAM=TEAM_IDENTIFIER
```

公開用の既定Bundle IDは`app.ringonomitv.tv`です。既存の個人用インストールを更新する
場合は、Bundle IDを環境変数で指定できます。

```sh
PRODUCT_BUNDLE_IDENTIFIER=your.private.bundle.id \
  ./deploy.sh DEVICE_IDENTIFIER DEVELOPMENT_TEAM=TEAM_IDENTIFIER
```

DEBUGビルドでは、サーバーURLを保存せず実行時引数で指定できます。

```text
--server-url https://example.invalid:7000 --play-channel gr011
```

`--server-url`、`--play-channel`、`--play-recording`、`--show-recordings`、`--show-guide`、`--show-reservations`、障害表示確認用の引数はDEBUG
ビルドだけに含まれます。

## CI

GitHub ActionsではmacOS 15上のXcode 16.4を使い、TVVLCKitバイナリを必要としない
Swiftパッケージテストと通信契約チェックを実行します。TVVLCKitを含むアプリ本体の
署名・実機検証は、各開発者のローカル環境で行います。
非公開リポジトリでは自動CIを抑止し、明示的な手動実行時だけ実行します。

## ロードマップ

1. 起動、バッファリング、画質変更、割り込みからの復帰を安定させる
2. 番組表・録画予約を仕上げ、キーワード条件の編集範囲を広げる
3. 再生位置・チャプター・CMスキップを仕上げ、字幕・実況・録画の主副音声対応を広げる
4. 対応バックエンドとSMBメディアを拡張する
5. フォーカス移動、アクセシビリティ、長時間再生、リリースQAを仕上げる

各項目は、ユニットテスト、クリーンビルド、対象となるバックエンド・実機確認が
そろった時点で受け入れます。
