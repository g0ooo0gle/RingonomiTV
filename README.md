# りんごのみTV（RingonomiTV）

りんごのみTVは、自分で運用する録画・視聴サーバーに接続するApple TV向けの
オープンソースtvOSアプリです。KonomiTVに加え、MirakurunのTS直接視聴と
EPGStationの番組表・ライブ視聴・録画再生・録画予約・キーワード予約に対応しています。

本アプリは、[Komorebi](https://github.com/BeerEgg2001/Komorebi)の機能と通信仕様を
参考に、Swift／SwiftUI／tvOS向けに再実装しています。参照元Androidプロジェクトの
MIT著作権表示は、このリポジトリの[`LICENSE`](LICENSE)に保持しています。

## 主な機能

| 分野 | 機能 |
| --- | --- |
| ライブ視聴 | チャンネル一覧、検索、お気に入り、並び替え、視聴中の画質変更 |
| 録画再生 | 続き再生、シーク、チャプター、CM自動スキップ、サムネイルからのシーンサーチ |
| 音声・字幕・実況 | 複数音声の選択、KonomiTVのライブ・録画ARIB字幕、ライブ実況・録画過去ログ |
| 番組を探す | グリッド番組表、放送波・日付・検索による絞り込み、録画の分類・番組詳細 |
| 録画予約 | 予約の追加・変更・取消、キーワード自動予約と検索プレビュー |
| ファイル再生 | EPGStationの動画ファイル選択、SMB共有のフォルダー一覧・ピン留め・動画再生 |
| 表示 | 外観・季節の配色、L字クロップ、KonomiTV録画のPiP |

利用できる機能は接続先や配信形式によって異なります。この文書は開発中のソースの対応範囲を示しています。
各ベータ版の確認済み機能・既知の制限は、リリースノートで案内します。

### 対応する接続先

| 接続先 | 番組・録画を探す | 再生 | 録画予約 |
| --- | --- | --- | --- |
| KonomiTV | 番組表・チャンネル・録画一覧 | ライブ・録画 | 通常予約・キーワード予約 |
| Mirakurun | サービス一覧・番組表 | TSライブ | — |
| EPGStation | 番組表・録画一覧 | ライブ・録画 | 通常予約・キーワード予約ルール |
| SMB共有 | フォルダー一覧 | 動画ファイル | — |

### 知っておきたい制限

- ARIB字幕はKonomiTVのライブTS・録画HLS、PiPはKonomiTVの録画が対象です。
- Mirakurunの画質変更・録画予約、リバースプロキシのBasic認証には未対応です。
- EPGStationの詳細な変換設定の編集は未対応で、録画中ファイルの追従は未検証です。
- SMBで総時間を取得できないTSは、時間シークと続き再生に対応しません。

操作方法と接続先ごとの詳しい制限は、[使い方と対応範囲](docs/USAGE.md)を参照してください。

## 導入

tvOS 17以降のApple TV HD／4Kと、ビルド用のMacが必要です。
MacにはXcode 16.4以降とCMake 3.28以降を用意します。

ソースを取得して、依存物の準備・テスト・ビルドを実行します。

```sh
git clone https://github.com/g0ooo0gle/RingonomiTV.git
cd RingonomiTV

./bootstrap.sh
./test.sh
CODE_SIGNING_ALLOWED=NO ./build.sh
```

Apple TVへの配置には、Xcodeでの署名設定と端末のペアリングが必要です。
依存物の取得元・検証ハッシュ、保存先の変更、署名・配置の手順は
[ビルドとApple TVへの配置](docs/BUILDING.md)にまとめています。

## 使い方

1. アプリの設定で、利用するサーバーやSMB共有を登録します。
2. ライブ一覧・番組表・録画ライブラリから番組を選び、詳細画面から再生します。
3. 再生画面の操作パネルから、画質・音声・字幕などを選べます。録画はシークバーで移動できます。

再生開始・画質変更・再バッファリング中は、映像と音声の準備が整うまでローディングを表示します。
通信や再生に問題がある場合は、再試行または停止を選べます。

[番組の探し方・再生操作・録画予約の詳細](docs/USAGE.md)

## 設定

| 設定 | 内容 |
| --- | --- |
| 接続先 | サーバーURLやSMB共有を登録します。初期状態のサーバーURLは空です。 |
| サーバーアカウント | 必要に応じてKonomiTVへログインします。ログインなしで利用できる機能もあります。 |
| 表示 | システム・ダーク・ライトの外観と、標準・春・夏・秋・冬の配色を選べます。 |

[接続・認証・表示設定の詳細](docs/USAGE.md#接続と表示を設定する)

## CI

GitHub ActionsではmacOS 15上のXcode 16.4を使い、TVVLCKitバイナリを必要としない
Swiftパッケージテストと通信契約チェックを実行します。TVVLCKitを含むアプリ本体の
署名・実機検証は、各開発者のローカル環境で行います。
非公開リポジトリでは自動CIを抑止し、明示的な手動実行時だけ実行します。

## ロードマップ

現在の着手状況と未完了項目は[進捗管理Issue](https://github.com/g0ooo0gle/RingonomiTV/issues/9)で追跡しています。

1. 起動、バッファリング、画質変更、割り込みからの復帰を安定させる
2. 番組表・検索・録画ライブラリから番組を探す操作を仕上げる
3. 録画予約・キーワード予約の編集と異常時の確認フローを仕上げる
4. 再生位置・チャプター・CMスキップを仕上げ、字幕・実況・主副音声対応を広げる
5. 対応バックエンドとSMBメディアを拡張する
6. L字クロップ・テーマ・二画面・PiP・アプリ内小窓・AI機能を段階的に追加する
7. フォーカス移動、アクセシビリティ、長時間再生、リリースQAと導入文書を仕上げる

各項目は、ユニットテスト、クリーンビルド、対象となるバックエンド・実機確認が
そろった時点で受け入れます。

動作する機能のまとまりごとに、`v0.1.0-beta.N` のような小刻みなベータ版を公開します。
各版のリリースノートで、確認済みの機能、既知の制限、未確認の範囲を案内します。
