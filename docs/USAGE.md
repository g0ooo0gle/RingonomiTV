## 番組を探す

### ライブ一覧

ライブ一覧は局名・放送中の番組名・表示番号を検索できます。空白で区切った語はすべてを含むチャンネルに絞り込みます。

お気に入りの追加・解除、お気に入りだけの表示、先頭への並べ替えに対応します。お気に入りは接続先ごとにApple TVへ保存します。

### 番組表

番組表はチャンネルを横、時間を縦に並べ、朝4時を一日の境界として表示します。左右でチャンネル、上下で番組を選び、決定で詳細を開きます。チャンネル別の一覧表示にも切り替えられます。

放送波・日付の切り替え、日本語検索、副チャンネルの表示に対応します。番組詳細から視聴や録画予約へ進めます。利用できる操作は接続先によって異なります。

Mirakurunでは、設定またはサービス一覧から放送波・日付を選び、これから始まる番組を検索できます。番組詳細からチャンネルのTSライブ視聴を開始します。

### 録画ライブラリ

録画ライブラリは30件ずつ表示し、番組名・シリーズ名・サブタイトルの部分一致で検索できます。新旧順の並べ替え、チャンネル・ジャンル・曜日・シリーズ別の分類、番組詳細を利用できます。

分類対象は最大20,000件です。シリーズ情報がない録画は、話数表記を除いた番組名が複数件で一致する場合にまとめ、それ以外は「単発・その他」に表示します。全件表示ではサーバーのページを順に閲覧できます。録画中・一部録画の状態も表示します。

EPGStationでは録画一覧・検索・番組詳細に加え、再生する動画ファイルを選べます。

## 視聴・再生する

### 基本操作と状態表示

再生画面の上下の操作パネルから、画質や音声などを選べます。リモコンの再生／一時停止ボタンで再生状態を切り替え、録画ではシークバーから再生位置を選べます。戻るボタンは、開いている選択画面やパネルを閉じた後、再生画面を閉じます。

KonomiTVでは1080p・720p・540p・360pを選べます。視聴中の画質変更はKonomiTVとEPGStationで利用でき、選択肢は接続先の配信設定によって異なります。

再生開始時、画質変更時、再バッファリング時は、映像と音声が利用可能になるまでローディングを表示して音声を出しません。準備中に停止した場合は再生を止め、通信や配信が途切れた場合は再試行または停止を選べます。字幕や実況の処理に失敗しても映像再生は継続し、実況はメニューから再接続・再取得できます。

### 続き再生・チャプター・CMスキップ

録画の再生位置はApple TVごとに保存します。前回の位置がある録画は続きから再生するか最初から再生するかを選べます。完了間近まで再生した録画は次回に最初から開きます。

| 操作 | 動作 |
| --- | --- |
| チャプター | サーバーのCM区間情報に基づき、本編・CMの開始位置へ移動します。区間情報がない場合は1分戻る・3分進むを利用できます。 |
| CM自動スキップ | 既定はオフです。完了済みでCM区間情報がある録画のCM終了位置へ移動します。スキップ後30秒以内は元の位置へ戻せます。 |
| シーンサーチ | サーバーが生成した時刻付き画像から再生位置を選べます。画像がない場合もシークバーと時間指定の移動は利用できます。 |

CM自動スキップは一時停止中・読み込み中・不整合な区間には適用しません。CM判定はサーバーの解析結果に依存します。

### 音声・実況・字幕

複数音声を認識した配信では再生画面の「音声」から切り替えられます。画質変更後も音声を一意に識別できる場合は選択を引き継ぎます。音声がない、または同名で区別できない場合は案内を表示し、映像は再生を続けます。

- 録画実況は過去ログの表示・非表示、右から流れるコメント、上下の固定コメント、色・文字サイズ、シーク・画質変更後の再同期に対応します。取得に失敗しても映像は再生を続け、メニューから再取得できます。
- ライブ実況は対応チャンネルのNX-Jikkyoから受信し、表示遅延を0〜10秒で調整できます。一時停止・読み込み中は時計を止め、切断時は待ち時間を延ばしながら再接続します。映像の配信遅延は環境に依存するため、放送時刻との厳密な同期ではなく映像に合わせて調整します。
- KonomiTVのライブTS・録画HLSのARIB字幕をlibaribcaptionで描画し、放送指定の色・背景・位置を反映します。「字幕」から表示を切り替えられます。ライブ字幕の同期を戻したい場合は「映像と字幕を再読み込み」を選べます。録画のシークや続き再生の直後は、次の字幕データを受信するまで表示されないことがあります。

### 画面調整・PiP

L字クロップと各辺の余白調整を利用できます。

KonomiTVの録画はPiPに対応します。小窓から一覧操作や全画面への復帰ができ、別の番組を開くと元のPiPを終了して切り替えます。アプリ側のARIB字幕・実況・クロップは小窓には反映されません。

### 接続先ごとの再生

EPGStationのライブは無変換配信を優先します。無変換がない場合は変換を自動開始せず、画質を明示的に選択します。HLSプレイリストが準備できるまで待機し、準備中・再生中は配信維持要求を送ります。停止・画質変更・再試行では旧配信を停止して準備し直します。

SMB共有はフォルダーの一覧、ピン留め、動画再生に対応します。総時間とシーク可否を確認できる動画では「続きから再生」「先頭から再生」を選べます。保存後に再生時間が変わった場合は先頭からの再試行を案内します。

## 録画を予約する

### KonomiTV

番組詳細から録画予約を追加し、「予約」タブから一覧の確認・設定変更・削除ができます。優先度、録画マージン、保存先、録画後処理などの設定に対応します。

キーワード予約は、対象チャンネル、番組長、重複チェック、ジャンル（大分類・中分類）、曜日・時間帯、正規表現・あいまい検索、除外条件を組み合わせられます。曜日・時間帯は日本時間の番組開始日時で判定し、保存前に検索結果を確認できます。

通常予約・キーワード予約では、対応する画面で保存先フォルダー、ファイル名テンプレート、ワンセグ用保存先、録画後の動作を設定できます。録画後バッチはサーバー上のパスを接続先ごとに登録して選びます。予約変更画面での保存先・録画後処理の詳細編集は未対応です。

予約の追加・変更・削除を送信する直前に、操作内容をApple TVへ記録します。送信後に対象一覧を読み直し、書き込んだID・番組・設定が一致した場合だけ自動で記録を解除します。通信が切れた、応答が不正だった、処理を中止した、アプリを再起動した、送信後の一覧確認に失敗したなど結果を確認できない場合は、その記録を残して同じ操作の再送を止めます。HTTP 5xx、408・425・429、通信エラーやキャンセルも結果不明として扱います。送信そのものが明確に拒否されたHTTP 4xxだけは記録を解除して再試行できます。

結果不明の記録が残った場合は、記録に表示された接続先と種類（通常予約またはキーワード予約）の一覧を更新し、結果を確認してから「確認済み・操作を再開」を選んでください。別の接続先・種類の一覧や、記録より前の読み取りでは解除できません。記録が壊れている場合は通常の解除操作を使えず、現在の接続先で通常予約とキーワード予約の両方を更新して結果を確認した後、表示された復旧操作で解除します。保存記録の解除に失敗した場合も記録は残り、再送は停止します。

### EPGStation

| 対象 | 利用できる操作 |
| --- | --- |
| 予約 | 一覧・詳細、競合・スキップ・重複除外による絞り込み、番組指定・日時指定の追加 |
| 手動予約 | 末尾切れ設定の変更・取消 |
| ルール予約 | 回単位の除外 |
| キーワード予約ルール | 一覧・検索・追加・編集・有効無効の切り替え・削除、番組検索プレビュー |

キーワード予約は無効状態で作成し、検索プレビューを確認してから保存します。編集しないタグ、保存先、変換設定、サーバー拡張項目は保持します。

ルール操作や予約操作で通信結果が不明な場合は自動再送しません。表示された接続先の一覧を更新して確認してから再開します。

## 接続と表示を設定する

### サーバーアカウント

設定の「サーバーアカウント」からKonomiTVへログインできます。認証情報は接続先ごとにApple TVのKeychainへ保存し、パスワードは保存しません。HTTPS接続を使用し、認証切れは設定から再ログインできます。アカウントなしで利用できる機能はログインせずに利用できます。

SMBの認証情報もApple TVのKeychainへ保存します。

### 外観

設定の「表示」で外観をシステム・ダーク・ライト、配色を標準・春・夏・秋・冬から選べます。番組表の背景・文字・選択枠と再生パネルに反映されます。

## 制限と未対応の機能

| 対象 | 制限 |
| --- | --- |
| KonomiTVの認証 | リバースプロキシのBasic認証は未対応です。 |
| ARIB字幕 | KonomiTVのライブTS・録画HLSが対象です。複数の字幕言語の選択は未対応で、外字は受信データと描画ライブラリの対応範囲に依存します。 |
| PiP | KonomiTVの録画が対象です。ライブや他のバックエンドのPiPは未対応です。 |
| Mirakurun | 画質変更・録画予約には対応していません。チャンネル取得失敗時は取消・再試行を利用できます。 |
| EPGStation | 詳細な変換設定の編集、ライブ／直接TSの字幕表示は未対応です。録画中ファイルの追従は未検証です。 |
| 予約編集 | 予約変更画面での保存先・録画後処理の詳細編集は未対応です。 |
| SMB | 総時間を取得できないTSは時間シークと続き再生に未対応です。認証失敗時の表示、接続方式・ポート制御は改善中です。 |
